# 로비 · 상세 · 영입 UI 모션

기준 커밋: `8bb7ed6` (대기 모션 적용 v0.4.0)

기존 영상은 그대로 사용하며, 이번 변경은 UI를 React/CSS/SVG로 연출한다. 새 힉스필드 생성이나 의존성 추가는 없다.

| 화면 | 구현 |
| --- | --- |
| 소파·역 로비 | 메뉴별 순차 등장, 그림/클릭 영역이 함께 반응하는 hover·focus·press, 짧은 위치 타이포, 흐르는 하단 띠 |
| 캐릭터 상세 | 독립된 파랑/아이보리 사선, 대형 이름·정보 이름의 글자별 마스크, 캐릭터 교체, 능력치 행 reveal, 탭 표시 이동 |
| 영입 | 네 배너 선택 커서, 사선 전환, 라이브 제목, ON AIR 띠, 상단/하단 UI 순차 등장, 버튼 강조 |

원본 이미지에 묶여 있던 상세 왼쪽 배경과 영입 제목은 같은 색/배치 계열의 코드 그래픽으로 다시 그렸다. 원본 픽셀과 동일한 디자인은 아니다. 다른 캐릭터와 다른 영입 배너의 기존 임시 아트는 그대로다.

`src/ui/ui-motion.tsx`에서 화면 활성/백그라운드/모션 감소를 처리한다. `MotionItem`은 그림·동적 값·클릭 영역의 원본 좌표를 함께 유지한다. `src/styles/ui-motion.css`는 이 네 캔버스에만 적용된다.

## 로컬 확인

```sh
npm ci
npm run dev
```

개발 주소에 `?screen=lobby`, `?screen=characterDetail`, `?screen=recruit`를 붙여 진입한다. 로비의 테마 버튼으로 소파/역을 전환한다. 모바일은 844×390 가로 화면에서 확인했다.

```sh
npm run build
npx playwright install chromium
node tests/ui-motion.mjs
```

전용 테스트는 Vite를 스스로 시작/종료한다. 로비 실제 클릭, 겹친 역 카드, 감상 모드, 캐릭터 교체, 상세 탭, 성장 팝업 취소, 영입 배너·정보창, 재화 불변, 영상 정지 후 UI 동작, OS/앱 모션 감소, 모바일 터치를 검증한다. 테스트 캡처는 `test-results/ui-motion/`에만 생성된다.

검증 환경은 Chromium 데스크톱과 모바일 에뮬레이션이다. 실제 iOS/Android 기기 성능은 미검증이다. 기존 영상의 머리카락 알파 테두리는 이번 UI 작업으로 수정하지 않았다.
