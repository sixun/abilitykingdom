# 어빌리티킹덤 — 능력치·성장 시스템

기준일: 2026-10-15

이 문서는 대화에서 확정한 기획과 아직 미정인 세부 규칙을 구분한다. 기획 확정은 코드 구현 완료를 의미하지 않는다.

## 1. 능력치 — 20종 확정

| 번호 | 구분 | 능력치 | 효과 |
|---|---|---|---|
| 1 | 기본 | 최대 체력 | 생존 가능한 피해량 |
| 2 | 기본 | 공격력 | 공격·어빌리티의 공격력 계수에 적용 |
| 3 | 기본 | 방어력 | 받는 피해 감소 계산에 적용 |
| 4 | 기동 | 공격 속도 | 기본 공격 주기 단축 |
| 5 | 기동 | 이동 속도 | 이동·접근 속도 증가 |
| 6 | 공격 | 치명타 확률 | 치명타 발생 확률 |
| 7 | 공격 | 치명타 피해 | 치명타 피해 배율 |
| 8 | 공격 | 방어 관통률 | 대상 방어력의 일부를 무시 |
| 9 | 공격 | 일반 공격 피해 증가 | 기본 공격 피해 강화 |
| 10 | 공격 | 어빌리티 피해 증가 | 어빌리티의 직접 피해 강화 |
| 11 | 공격 | 지속 피해 증가 | 출혈·중독·화상 등의 지속 피해 강화 |
| 12 | 운용 | 재사용 대기시간 감소 | 어빌리티 쿨타임 단축 |
| 13 | 효과 | 효과 적중 | 확률형 해로운 효과의 적용 확률 증가 |
| 14 | 효과 | 효과 저항 | 확률형 해로운 효과에 걸릴 확률 감소 |
| 15 | 효과 | 버프 지속시간 증가 | 자신이 부여하는 버프의 지속시간 증가 |
| 16 | 지원 | 치유 효과 증가 | 자신이 제공하는 치유량 증가 |
| 17 | 지원 | 보호막 효과 증가 | 자신이 생성하는 보호막의 흡수량 증가 |
| 18 | 생존 | 받는 피해 감소 | 방어력과 별도로 받는 피해 감소 |
| 19 | 생존 | 받는 치유량 증가 | 자신이 받는 치유량 증가 |
| 20 | 생존 | 군중제어 시간 감소 | 자신에게 걸린 기절·속박 등의 지속시간 단축 |

- 캐릭터 종합 전투력·편성 종합 전투력은 넣지 않는다.
- 개별 능력치는 표시한다.
- 능력치별 기본값·계산식·상한·예외 적용 규칙은 미정이다.
- 효과 저항은 적용 확률, 군중제어 시간 감소는 적용된 효과의 지속시간에 관여한다.
- 치유 효과는 치유 제공자, 받는 치유량은 치유 대상의 수치다.

## 2. 캐릭터별 성장

| 항목 | 확정한 내용 |
|---|---|
| 랭크 | 캐릭터 고유 설정. 성장해도 바뀌지 않음 |
| 티어 | 1성~8성. 전체적인 능력치에 %로 영향 |
| 레벨 | 전투 EXP와 경험치 아이템으로 성장. 전체적인 스탯이 고루 상승 |
| 레벨 돌파 | 10레벨 단위로 돌파해야 다음 레벨 구간 진입 가능 |
| 어빌리티 | 스킬마다 독립적인 레벨·성장 게이지 보유 |
| 공명 | 캐릭터를 장착하고 전투에 참여하는 시간으로 쌓이는 애정도 성격의 성장 |

### 2.1 랭크

- 캐릭터의 고유 설정이며 변경되지 않는다.
- 구체적인 랭크 구분은 미정이다.

### 2.2 티어

- 1성부터 8성까지 존재한다.
- 전체적인 능력치에 %로 영향을 준다.
- 상승 조건·필요 재료·단계별 증가율·적용 대상 능력치는 미정이다.

### 2.3 레벨·돌파

- 전투 등으로 EXP를 획득한다.
- 경험치 캡슐·책 같은 아이템으로도 레벨을 올릴 수 있다. 아이템 명칭은 미정이다.
- 레벨 상승으로 전체적인 스탯이 고루 오른다. 정확한 적용 능력치와 성장량은 미정이다.
- 10레벨 단위로 돌파가 필요하다.
- 돌파하지 않아 레벨이 막혀 있어도 경험치는 계속 누적된다.
- 돌파하면 누적 경험치를 계승해 레벨에 적용한다.

| 도달 레벨 | 다음 구간으로 가기 위한 돌파 | 단계별 성공 확률 |
|---|---|---|
| 10레벨 | 1돌파 | 1단계 100% |
| 20레벨 | 1돌파 → 2돌파 | 1단계 100%, 2단계 80% |
| 30레벨 | 1돌파 → 2돌파 → 3돌파 | 1단계 100%, 2단계 80%, 3단계 50% |

앞 구간에서 성공했던 돌파도 새 구간에서는 다시 해야 한다. 예를 들어 10레벨에서 1돌파를 했어도, 20레벨에서는 1돌파와 2돌파를 모두 다시 진행한다.

미정 사항:

- 돌파 재료와 소모량
- 실패 시 현재 단계 유지 여부 또는 돌아가는 단계
- 천장·실패 보정 유무
- 40레벨 이후 단계별 확률
- 최대 레벨
- 누적 EXP가 다음 돌파 구간까지 넘는 경우의 적용 세부 규칙

### 2.4 어빌리티

캐릭터당 패시브·액티브·버프·각성, 총 4개 스킬을 가진다.

| 스킬 | 성장 방식 |
|---|---|
| 패시브 | 개별 레벨·게이지 |
| 액티브 | 개별 레벨·게이지 |
| 버프 | 개별 레벨·게이지 |
| 각성 | 특수 조건으로 개방. 조건 미정이라 현재 성장 설계에서는 보류 |

- 1레벨부터 게이지를 채우며 성장한다.
- 패시브·액티브·버프는 10레벨까지 공통 재화를 사용한다.
- 10레벨 이후에는 특화 재화를 사용한다.
- 특화 재화로 전환되는 정확한 강화 단계, 특화 재화 구분 기준, 최대 레벨과 필요량은 미정이다.

### 2.5 공명

- 좋아하는 캐릭터를 계속 사용하며 쌓는 성장이다.
- 캐릭터를 장착하고 전투에 참여하는 시간을 기준으로 한다.
- 부여 능력치·보상·최대치·시간 인정 조건은 미정이다.

## 3. 팀 전체에 적용되는 성장 — 3종

| 시스템 | 확정한 구조 | 성장 방식 |
|---|---|---|
| 코어 | 스토리 챕터 마지막 보스 클리어마다 슬롯 추가 해금 | 재화로 랜덤 옵션 재설정. 코어 자체 레벨 존재 |
| 엑셀리티 | E · X · C · E · L · I · T · Y, 총 8개 항목 | 각각 레벨업. 팀 전체 캐릭터의 고유 스탯 강화 |
| 전략 | 총 8칸의 능력치 옵션 | 옵션 재설정과 수치 성장 |

### 3.1 코어

- 스토리 1챕터 마지막 보스 클리어 → 첫 번째 슬롯 해금.
- 2챕터 마지막 보스 클리어 → 두 번째 슬롯 해금.
- 이후 같은 방식으로 추가 해금한다.
- 해금한 코어에 재화를 사용해 랜덤 옵션을 맞춘다.
- 코어 레벨이 별도로 존재한다.

미정 사항:

- 코어별 옵션 개수와 최대 슬롯 수
- 등장 능력치와 확률·수치 범위
- 레벨업 효과·최대 레벨·재료
- 옵션 재설정 시 레벨·수치 보존 여부

### 3.2 엑셀리티

- 메이플 아케인 심볼처럼 꾸준히 쌓는 내실 성장이다.
- E / X / C / E / L / I / T / Y, 8개를 각각 성장시킨다.
- 두 개의 E도 별도 항목이다.
- 강화 효과는 팀 전체에 적용된다.
- 캐릭터의 고유적인 스탯을 강화한다.

미정 사항:

- ‘캐릭터 고유 스탯’이 구체적으로 의미하는 능력치
- 각 글자에 배치할 강화 능력치
- 해금 조건·획득처·성장 재료·최대 레벨

### 3.3 전략

| 항목 | 확정한 내용 |
|---|---|
| 슬롯 | 8칸 |
| 전체 재설정 | 8칸 전체를 돌릴 수 있음 |
| 잠금 재설정 | 원하는 n칸을 잠그고 나머지만 돌릴 수 있음 |
| 개별 재설정 | 1칸만 돌릴 수 있음 |
| 전용 옵션 | 1칸만 돌릴 때 나오는 능력치가 존재 |
| 필수 옵션 | 약 4종을 필수급으로 설계할 의도 |
| 랜덤 수치 | 각 칸 0~10% 사이 랜덤 |
| 수치 성장 | 100%까지 성장 가능 |
| 성장 재화 | 한 칸 집중 성장 재화 / 전체 칸 성장 재화가 각각 존재 |

미정 사항:

- 100%가 실제 능력치 효과인지, 성장 완성도인지
- 0~10%의 정확한 적용 시점과 이후 성장 방식
- 재설정할 때 기존 성장 수치를 유지하는지
- 일반 옵션 목록·개별 재설정 전용 옵션 목록·필수급 약 4종
- 중복 옵션 허용 여부·확률·잠금 비용·성장 재화 소모량

## 4. 다음 설계 대상

20종 능력치와 성장 시스템 종류는 정했으며, 시스템별 능력치 배치는 아직 미정이다.

1. 레벨·티어가 어떤 능력치를 얼마나 올리는지
2. 공명이 주는 능력치·보상
3. 코어의 랜덤 옵션 목록과 레벨 효과
4. 엑셀리티 8개 각각의 강화 능력치
5. 전략의 일반 옵션·개별 재설정 전용 옵션·필수급 약 4종
6. 능력치별 기본값·계산식·상한·중첩·예외 규칙
7. 성장 재화의 스토리·현상수배·훈련·도시탐색·아레나·레이드 보상 배치
8. 상점에서 판매할 재화·상품

설계 방향은 약간 복잡해서 조합을 고민할 수 있게 배치하고, 직접 테스트하면서 수정하는 것이다.

‘레벨·티어는 체력·공격력·방어력만 올린다’는 제안은 아직 확정하지 않았다. 전략의 100%를 성장 완성도로 환산하는 제안 역시 확정하지 않았다.
