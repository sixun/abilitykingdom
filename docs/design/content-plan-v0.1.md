# 어빌리티킹덤 — 인게임 콘텐츠 상세기획 v0.1

작성일: 2026-10-15 (KST)  
범위: 스토리 · 현상수배 · 훈련 · 도시탐색 · 아레나 · 레이드  
문서 상태: 제작 검토용 초안. 확정 기획과 신규 제안을 구분하며, 구현 완료를 의미하지 않는다.

## 1. 이 문서의 기준

### 1.1 확정된 전제

- 전투에는 SD 캐릭터가 등장한다. 캐릭터 외형과 설정을 유지하는 것이 최우선이다.
- 콘텐츠는 스토리, 현상수배, 훈련, 도시탐색, 아레나, 레이드의 6종이다.
- 캐릭터 종합 전투력과 편성 종합 전투력은 표시하지 않는다. 개별 능력치는 확인할 수 있다.
- 캐릭터 성장은 랭크, 티어, 레벨·돌파, 어빌리티, 공명으로 구성된다. 랭크는 성장으로 바뀌지 않는 고유 설정이다.
- 팀 공통 성장은 코어, 엑셀리티, 전략이다.
- 스토리 챕터 마지막 보스를 클리어하면 코어 슬롯이 하나씩 열린다.
- 성장 구조는 어느 정도 복잡성을 허용하고 실제 플레이 테스트로 조정한다.
- 현상수배를 고정 대상의 무한 재체포로 구성하는 것에 문제가 제기되었다. 구체적 운영 방식은 아직 확정하지 않았다.

성장 규칙은 별도 문서 「어빌리티킹덤_능력치_성장기획.md」의 2026-10-15 내용을 기준으로 한다. 본 문서가 그 문서의 확률·옵션·수치를 변경하지 않는다.

### 1.2 이번 문서에서 제안하는 것

이하의 콘텐츠 규칙, 가칭 장소·사건, 해금 시점, 전투 시간, 보상 배분, 상점, 제작 순서는 별도 확정 표시가 없으면 모두 **제안**이다. 플레이 가능한 첫 버전의 기준을 제시하기 위해 구체적인 값을 둔 것이며 최종 밸런스가 아니다.

- 스토리: 사건을 해결하면서 다음 지역과 성장 기능을 개방.
- 현상수배: 의뢰를 선택하고 대상별 조건을 충족하는 짧은 전술 전투.
- 훈련: 예측 가능한 과제와 보상으로 육성을 보조.
- 도시탐색: 경로·사건·귀환을 선택하는 중기 탐색.
- 아레나: 고정 경기장에서 다른 유저의 편성과 겨루는 경쟁.
- 레이드: 고정 전장에서 대형 보스의 패턴을 공략하는 장기 목표.

### 1.3 아직 잠그지 않는 전제

2D/3D 제작 방식, 카메라 각도, 조작 방식, 편성 인원, 실시간/턴제, 스킬 조작 범위는 이 문서에서 최종 결정하지 않는다. 아래 시간은 실시간 전투를 가정한 시험값이며 턴제라면 턴 수로 재설계한다. 이동·대상 지정이 불가능한 전투 방식이라면 추격·장치 상호작용 과제를 그대로 구현하면 안 된다.

## 2. 콘텐츠 간 역할과 성장 관계

수직 성장은 난도를 돌파할 능력과 성장 자원을 얻는 구조다. 수평 콘텐츠는 다른 편성·공략·선택을 활용하고 수집·기록·탐색 범위를 넓히는 구조다. 하나의 모드에 두 성격이 함께 있을 수 있다.

| 콘텐츠 | 중심 성격 | 플레이어가 반복해서 판단할 것 | 주 성장 연결 | 권장 회차 길이 |
|---|---|---|---|---|
| 스토리 | 수직 개방 + 서사 | 사건에 맞는 편성·목표 공략 | 코어 슬롯, 기능 해금, 초회 성장 재료 | 일반 전투 60~120초, 이야기 별도 |
| 현상수배 | 수평 공략 + 수직 재료 | 대상·조건·보상의 선택 | 돌파, 어빌리티 특화 재료 | 90~150초 |
| 훈련 | 수직 성장 보조 + 숙련 | 필요한 재료와 과제 선택 | EXP, 공통 어빌리티 재료 | 45~90초 |
| 도시탐색 | 수평 탐색 + 누적 내실 | 경로·사건·귀환 판단 | 엑셀리티, 코어 성장·재설정 재료 | 탐색 6~10분, 전투 2~3회 |
| 아레나 | 경쟁·편성 연구 | 상대 선택과 대응 편성 | 명예·외형, 제한된 선택 재료 | 90초 상한 시험 |
| 레이드 | 수직 고점 + 수평 역할 조합 | 패턴·페이즈 대응 | 전략 성장, 고급 선택 재료 | 180초 상한 시험 |

**구분 원칙:** 훈련의 최고 난도가 현상수배보다 어렵다는 식으로 숫자만 구분하지 않는다. 같은 전투 엔진에서도 목표, 정보 제공, 연속성, 종료 조건을 달리한다.

## 3. 공통 플레이·연출 규칙

### 3.1 공통 진행 구조

`콘텐츠 선택 → 목적/조건 확인 → 편성 → 시작 장면 → 전투/탐색 → 목표 판정 → 후속 장면 → 결과·보상 → 다음 행동`

| 구간 | 반드시 보여줄 정보 | 설계 규칙 |
|---|---|---|
| 입장 전 | 목적, 적 특징, 필수 조건, 보상, 비용 | 전투력을 대신해 적의 능력과 목표를 구체적으로 설명 |
| 편성 | 참여 캐릭터, 역할 부족, 추천 대응 | 부족한 역할은 안내하되 특정 캐릭터 보유를 강제하지 않음 |
| 시작 | 현재 위치와 행동 이유 | 첫 방문은 맥락 제공, 반복은 짧게 |
| 진행 | 목표 진행도, 위협 예고, 중요한 사건 | 화면 밖 필수 적·장치를 놓치지 않게 알림 |
| 종료 | 성공·실패·부분 성공 사유 | 전멸과 임무 실패를 구분 |
| 결과 | 획득 재료, 초회/반복 보상, 다음 경로 | 이야기상 후퇴 장면에 환호하는 승리 연출 금지 |

### 3.2 초회와 반복의 분리

- 초회: 도입 설명, 캐릭터 대화, 현장 연출, 결말을 연결한다.
- 반복: 본 대사는 기본 생략 가능. 기믹 예고와 목표 정보는 생략하지 않는다.
- 스토리 재감상은 보상 없이 별도로 제공하는 방향을 제안한다.
- 재도전은 사건이 세계관에서 다시 발생했다는 뜻으로 취급하지 않는다. 초회 사건과 재도전 UI를 구분한다.
- 훈련은 실제로 반복 가능한 활동이므로 매 회차 새로운 사건 설명이 필요 없다.
- 소탕 여부는 모드별로 다르게 결정한다. 모든 콘텐츠를 소탕 메뉴로 통일하지 않는다.

### 3.3 비용·실패·중단

- PvE 입장 자원은 시작 시 예약하고 유효 결과 확정 시 소비하는 방식을 제안한다. 앱 종료·재접속으로 중복 보상을 얻을 수 없어야 한다.
- 스토리·훈련·현상수배는 실패 시 비용 미소비를 기본안으로 한다.
- 도시탐색은 첫 노드 진입에 탐색 상태를 생성한다. 중단 시 그 상태로 이어가며 새 탐색으로 보상을 중복 생성하지 않는다.
- 레이드·아레나는 유효한 도전 시작 이후 종료·이탈도 결과 정책을 적용한다. 불리할 때 앱 종료로 무효화할 수 없게 한다.
- 도시탐색의 선택지와 보상은 노드 확정 시 저장한다. 재접속으로 결과를 다시 뽑을 수 없다.
- 구체적 자원 이름, 회복 속도, 도전권 수량은 미정이다. 신규 모드마다 에너지 종류를 추가하지 않는 방향을 우선 검토한다.

## 4. 캐릭터 일관성·제작 규칙

### 4.1 외형 유지

캐릭터마다 승인된 원본, 정면/측면 기준, 색상, 비율, 무기, 장식 위치, 손잡이, 표정 범위를 한 묶음으로 관리한다. 콘텐츠마다 새로 그린 유사 캐릭터로 대체하지 않는다.

| 대상 | 공통 사용 | 추가 제작이 필요한 경우 |
|---|---|---|
| SD 기본 외형 | 6개 콘텐츠에서 동일한 기준 자산 사용 | 새로운 의상·손상 상태가 기획된 경우 |
| 기본 모션 | 대기, 이동, 공격, 피격, 전투 불능, 스킬 | 새 카메라 각도, 새로운 동작이 꼭 필요한 경우 |
| 대화 | 승인된 초상화·표정 사용 | 해당 감정이 기존 표정으로 전달되지 않는 경우 |
| 장면 연출 | 위치 이동, 시선, 카메라, 음향, 이펙트 활용 | 잡기·운반·환경 상호작용 등 전용 동작 |

- 같은 자산을 공유해도 모든 각도와 행동을 공짜로 표현할 수 있는 것은 아니다. 전투 카메라와 이동 방향을 먼저 제한한 뒤 필요한 모션을 산정한다.
- 비대칭 의상·무기·장식이 있는 캐릭터는 좌우 반전 허용 여부를 별도로 지정한다.
- 연출 때문에 머리색, 얼굴 비율, 의상 구조, 무기를 바꾸지 않는다.
- 큰 스킬 이펙트가 캐릭터와 적의 필수 예고를 지속적으로 가리지 않게 한다.

### 4.2 성격과 세계관 유지

- 캐릭터별로 말투, 가치관, 능력 범위, 관계, 해서는 안 되는 행동을 정리한다.
- 성격이 미정인 캐릭터에게 임의의 주요 대사를 확정하지 않는다. 본 문서의 대사는 안내자·통신 역할을 기준으로 한다.
- 스토리 출연진과 전투 편성을 분리한다. 자유 편성의 모든 캐릭터가 정사상 현장에 있었다고 자동 해석하지 않는다.
- 중요한 인물의 결투·구출·배신 장면은 지정 출연진으로 연출한다. 지정 전투가 필요하면 체험 캐릭터를 제공하는 방식을 검토한다.
- 지정 편성 전투에서는 보유·육성 부족으로 이야기가 막히지 않도록 별도 조정한다.
- 스킬로 해결 가능한 장애물을 스토리에서 해결할 수 없다면 거리, 비용, 조건 등 설정상 이유가 필요하다.
- 승리 대사, 패배 대사, 생포 확인, 철수 대사를 구분한다. 생포 의뢰를 처치 연출로 끝내지 않는다.

### 4.3 현재 유지할 캐릭터 11명

샤오랑(기존 리온), 세렌, 이안, 칸나, 백린, 키요미, P(기존 장검), 연(기존 기모노), 도윤, 센카, 마유(여름 패스 캐릭터).

본 문서는 이들의 성격·능력·소속을 새로 확정하지 않는다.

## 5. 스토리 상세

### 5.1 목표와 구성

챕터마다 해결할 사건 하나와 인물 관계 변화 하나를 둔다. 장소를 옮길 때마다 왜 이동하는지가 앞 장면에서 제시되어야 한다.

첫 제작 챕터는 **이야기/조사 노드 3개 + 일반 전투 3개 + 목표 전투 1개 + 보스 전투 1개**의 8노드 구성을 제안한다. 길이는 첫 구현 후 조정한다.

### 5.2 챕터 1 예시 — 「끊어진 연락」(가칭)

| 노드 | 화면·사건 | 플레이 | 완료 후 변화 |
|---|---|---|---|
| S1-01 | 연락 두절 구역을 보여주는 지도와 대화 | 출동 목적 확인. 전투 없음 | 조사 지점 표시 |
| S1-02 | 차단된 골목, 현장 도착 SD 연출 | 소수 적과 첫 교전 | 진입로 확보 |
| S1-03 | 파손된 통신 장치 발견 | 조사 선택, 짧은 대화 | 주변 시설로 연결된 흔적 발견 |
| S1-04 | 통신 장치를 재가동하려 하자 적 접근 | 장치 방어 | 수신 기록 확보 |
| S1-05 | 기록이 가리킨 지점으로 이동 | 일반 교전, 새 적 행동 소개 | 중심 시설 진입 |
| S1-06 | 내부에서 봉쇄가 시작됨 | 증원과 우선 처리 대상의 조합 전투 | 보스 구역 개방 |
| S1-07 | 사건 배후와 대치 | 보스 패턴 공략 | 사건 원인 제거, 코어 슬롯 해금 조건 충족 |
| S1-08 | 현장 수습과 다음 단서 제시 | 결말 대화. 전투 없음 | 챕터 종료·코어 해금 안내 |

시설·적·사건 배후는 세계관에 맞춰 추후 확정한다. 코어 자체가 사건에서 발견된 물건인지는 미정이며, 해금 규칙만 확정된 상태다.

### 5.3 대표 전투 S1-04: 통신 장치 방어

- 목적: 수신 기록을 얻기 위해 장치 재가동이 완료될 때까지 방어한다.
- 맵: 장치를 중심으로 적 진입 경로 2개. 경로당 주요 교전 지점 1개. 카메라 밖 공격은 예고한다.
- 시험 시간: 75초. 장치 HP는 캐릭터 능력치가 아닌 스테이지 목표물 수치다.
- 시작: SD 캐릭터 도착 → 통신으로 재가동 안내 → 장치 표시 → 전투 개시.
- 0~20초: 일반 적으로 경로와 목표를 학습.
- 20~45초: 장치를 우선 공격하는 적 등장. 출현 전 경고와 대상 표시.
- 45~75초: 일반 적과 장치 공격 적을 함께 배치. 이전에 배운 대응을 조합.
- 성공: 75초까지 장치 생존. 남은 적이 있어도 임무 성공이며 후퇴·정리 연출로 연결.
- 실패: 장치 파괴 또는 전투 가능한 캐릭터 전멸.
- 후속: 기록 수신 장면 → S1-05 위치 표시 → 결과창.
- 반복: 도착 대화는 생략하되 장치 목표와 적 예고는 유지.
- 검증: 아무 행동 없이 전체 공격만 반복해도 최고 성과가 나오면 장치 공격 적의 압박·등장 위치를 수정한다.

### 5.4 난도와 보상

- 초반: 적 행동 하나를 안전하게 소개 → 다음 전투에서 다른 행동과 조합 → 보스에서 숙련 확인.
- 챕터 보스는 스토리 진행의 관문이지만 단순 체력 증폭으로 시간을 늘리지 않는다.
- 초회 보상은 성장 재료와 기능 개방에 집중한다.
- 반복 보상은 기본 EXP·일반 재화 수준으로 제한하고 전문 재료는 해당 콘텐츠로 유도한다.
- 코어 슬롯은 초회 보스 클리어에만 해금하며 재도전으로 추가되지 않는다.
- 스토리 진행 중 전투 패배가 의도된 경우에는 일반 실패 판정이 아닌 별도 연출 전투로 정의한다.

## 6. 현상수배 상세

### 6.1 구조: 갱신되는 의뢰 게시판

고정 범인을 매번 체포했다 풀어주는 구조 대신, **대상 유형 × 사건 × 지역 × 계약 조건**으로 의뢰를 구성한다. 재사용하는 적 외형이 동일 인물인지 동종 집단인지 명확히 구분한다.

고유 이름이 있는 주요 수배자는 초회 사건으로 처리한다. 클리어 이후 재도전은 기록 도전으로 구분하며 현재 체포 상태를 되돌리지 않는다.

| 게시판 항목 | 내용 |
|---|---|
| 대상 | 이름 또는 집단/개체 식별, 초상·실루엣 |
| 혐의·의뢰 이유 | 한두 문장으로 행동 목적 제공 |
| 지역 | 사용할 전장과 환경 특징 |
| 주요 행동 | 도주, 지원 호출, 장치 파괴 등 |
| 필수 목표 | 달성해야 완료되는 조건 1개 |
| 선택 목표 | 추가 성과 조건 최대 2개 |
| 보상 | 주 재료 종류와 수량, 추가 보상 |
| 기한 | 수락 전 갱신 시각과 수락 후 유지 규칙 |

첫 버전은 의뢰 3개 중 선택하는 방식으로 시험한다. 일일 갱신 시 수락한 의뢰는 진행 상태를 유지하고, 미수락 의뢰만 바뀐다. 동일 계정의 새로고침·재접속으로 의뢰가 다시 추첨되지 않도록 한다. 계정별 세부 의뢰는 달라도 같은 난도에서 보상 가치와 주간 재료 선택권이 유사해야 한다.

### 6.2 입장부터 종료까지

`의뢰 열람 → 조건/보상 선택 → 편성 → 현장 통신 1~2문장 → 대상 등장 → 계약 조건 전투 → 제압/회수 확인 → 의뢰 완료`

목표물 확보, 대상 제압, 도주 저지는 공용 목표 시스템으로 처리한다. 생포 목표는 HP 0에서 전투 불능·결박 연출로 전환하고 사망 연출을 쓰지 않는다. 막타를 특정 공격으로 제한하지 않는다.

### 6.3 첫 의뢰 유형 3종

| 유형 | 전장 구조 | 필수 목표 | 핵심 대응 | 실패 |
|---|---|---|---|---|
| 도주 저지 | 단일 길 + 출구 + 차단 장치 | 출구 도달 전 대상 제압 | 도주 예고 후 장치 차단 또는 제어 | 대상 탈출, 아군 전멸 |
| 지휘자 제압 | 중앙 대상 + 지원 진입로 2개 | 지휘자 제압 | 호출 중단 또는 지원 병력 처리 | 제한 시간 초과, 전멸 |
| 탈취품 회수 | 운반책 경로 + 물품 위치 | 물품 확보 후 잔여 위협 해소 | 운반책 우선 처리와 확보 지점 방어 | 물품 반출, 전멸 |

도주 저지는 이동 조작을 전제로 강제하지 않는다. 대상 선택·스킬 사용만 가능한 전투라면 차단 장치를 별도 명령으로 작동시키거나 도주 행동을 차단 가능한 캐스팅으로 바꾼다.

### 6.4 대표 의뢰 B-01: 도주 저지

- 입장 전 정보: 대상은 체력 50% 이하에서 출구로 도주. 도주 준비 4초. 전장에 1회용 차단 장치가 있다.
- 시작: 통신으로 대상 확인 → 대상이 출구 방향을 바라보는 짧은 장면 → 전투.
- 전반: 호위 적이 대상에게 접근하기 어렵게 만든다. 호위 전원 처치는 필수가 아니다.
- 전환: 체력 조건 달성 → 도주 준비 UI → 준비 종료 후 도주 시작.
- 대응: 차단 장치로 이동 경로를 막거나 제어 효과로 시간을 번다. 제어 캐릭터가 없어도 장치로 해결 가능하게 한다.
- 성공: 대상 제압. 장치 미사용·아군 생존 등 선택 목표로 소량 추가 보상.
- 실패: 탈출 후 실패 이유와 대응 정보를 표시한다. 비용은 미소비 제안.
- 보상: 기본 돌파 재료, 선택한 계열의 어빌리티 특화 재료. 무작위만으로 특정 캐릭터 육성이 장기간 막히지 않게 선택 의뢰를 보장한다.

### 6.5 난도 운영

기본 난도는 목표 행동 1개, 상위 난도는 지원 적·환경 변수 1개를 추가한다. 특정 효과 면역과 그 효과 필수 조건을 동시에 배치하지 않는다. 높은 난도는 재료 효율을 높이되, 기본 성장 재료를 저난도에서도 얻을 수 있게 한다.

## 7. 훈련 상세

### 7.1 구조

훈련 시설에서 제공하는 반복 과제다. 초회 도입에서 왜 훈련하는지와 보상 지급 주체를 설명하고, 이후에는 과제 브리핑만 표시한다. 담당자와 시설 명칭은 세계관 확정 후 부여한다.

**재료 획득 훈련**과 **자유 연습**을 탭으로 구분한다. 자유 연습은 자원·보상·공명 획득이 없고, 적과 조건을 바꾸며 편성 성능을 확인한다.

| 과제 | 목표 | 기본 보상 | 평가 지표 |
|---|---|---|---|
| 섬멸 훈련 | 정해진 적 전부 제압 | EXP 아이템 | 완료 여부, 클리어 시간 |
| 대응 훈련 | 예고 공격과 위험 대상에 대응 | 공통 어빌리티 재료 | 완료 여부, 위험 행동 허용 횟수 |
| 방어 훈련 | 목표물 생존 | 일반 성장 비용 재화 | 완료 여부, 목표물 잔여 HP |

### 7.2 대표 과제 T-02: 위험 행동 대응

- 시작: 오늘의 목표 표시 → 훈련용 적 기동 → 카운트다운.
- 1구간: 위험 행동 4초 전 표시. 하나의 적만 등장해 대응을 학습한다.
- 2구간: 일반 적 사이에 위험 행동 적을 배치한다. 우선 대상 선택을 요구한다.
- 3구간: 두 진입로에서 순차 등장. 처치 순서와 스킬 사용 시점을 조정한다.
- 성공: 정해진 웨이브 종료 시 아군 생존.
- 평가: 위험 행동을 몇 번 허용했는지 별도 표시한다. 모든 보상을 최고 평가에 몰아주지 않는다.
- 선택지: 행동 차단 스킬 외에도 시전 전 처치로 대응 가능하도록 한다.
- 종료: 위험 행동 허용 횟수·전투 시간 → 재료 지급 → 동일 과제 반복/다른 재료 선택.

### 7.3 반복과 시간 부담

- 수동 첫 클리어에서는 과제를 경험하게 한다.
- 최고 평가를 달성한 난도는 소탕 해금 후보로 둔다. 소탕 비용·보상은 정상 클리어와 동일하게 한다.
- 소탕으로 실제 전투 참여 시간을 만들어 공명을 지급하지 않는다. 공명 대체 지급을 도입하려면 별도 확정이 필요하다.
- 자유 연습으로 EXP·공명을 무한 획득하지 못하게 한다.
- 고난도 기록 경쟁은 선택 과제로 두고 일일 기본 보상과 분리한다.

## 8. 도시탐색 상세

### 8.1 구조: 도시 지도 + 사건 노드

자유 이동 3D 도시를 필수로 하지 않는다. 구역 지도에서 장소를 선택하고, 조사·대화·전투가 필요한 순간에 해당 화면을 연다. SD 캐릭터가 도착하거나 주변을 살피는 짧은 공통 연출로 공간감을 보완한다.

한 탐색은 시작점 → 선택 노드 4~6개 → 귀환으로 구성한다. 첫 버전에서는 전투 2~3회, 비전투 사건 2~3회를 목표로 한다. 노드 전체를 동일한 전투로 채우지 않는다.

### 8.2 탐색 중 유지되는 상태

| 상태 | 규칙 제안 |
|---|---|
| 캐릭터 HP | 전투 사이 유지. 휴식 사건에서 회복 |
| 전투 불능 | 탐색 안에서 유지. 구조/회복 사건으로 복귀 가능 |
| 스킬 쿨타임 | 새 전투에서 초기화하는 단순안으로 시작 |
| 조사 정보 | 탐색 내부의 경로·사건 해금에 사용 |
| 임시 획득물 | 귀환까지 보류되는 보상 |
| 지역 조사도 | 영구 진척. 첫 발견/첫 해결로 증가 |

정보는 콘텐츠 내부 상태이며 새 캐릭터 능력치가 아니다. 지역 조사도는 같은 노드를 무한 반복해 완성하지 않고 미발견 장소·사건을 통해 채운다.

### 8.3 사건 예시 E-03: 잠긴 창고

1. 외부에서 이상한 소리를 발견한다. 짧은 조사 문구와 선택지 표시.
2. 바로 진입: 경비와 전투. 승리하면 물자를 확보하지만 HP를 소모할 수 있다.
3. 주변 조사: 추가 노드가 열리고 우회 경로를 얻는다. 전투 없이 일부 물자를 확보할 수 있다.
4. 철수: 현재 획득물을 지키고 귀환한다.

세 선택은 항상 동일한 보상에 도달하는 장식이 아니어야 한다. 전투는 높은 획득량, 조사는 추가 정보·다른 발견, 철수는 안전한 확정이라는 차이를 준다. 특정 캐릭터가 있어야 유일한 정답을 고를 수 있는 구조는 첫 버전에서 제외한다.

### 8.4 귀환·실패

- 안전 귀환: 현재까지 확보한 임시 획득물 전부 확정.
- 전멸: 이미 영구 저장된 발견·조사도는 유지하고, 임시 획득물은 50% 보존하는 시험안을 적용.
- 반감 대상, 보존 수량과 소수점 처리는 탐색 진입 전에 안내한다. 퀘스트 필수 단서는 반감하지 않는다.
- 정해진 종료 노드까지 진행하면 추가 완료 보상을 지급한다.
- 앱 종료는 철수가 아니다. 현재 노드와 선택 상태를 저장하고 이어간다.
- 길을 잘못 골랐다는 이유로 탐색을 완전히 초기화하지 않는다. 막다른 길에도 발견이나 귀환 선택을 둔다.

### 8.5 지역 개방과 내실

스토리에서 방문한 구역을 탐색 지역으로 개방하는 구조를 제안한다. 지역별 사건 목록·적 조합·지도 연결을 달리하고, 조사도 달성 보상으로 엑셀리티 선택 재료를 지급한다. 특정 글자를 특정 지역에 영구 고정하는 것은 8개 항목의 효과 확정 후 결정한다.

반복 탐색에서는 엑셀리티 공통/선택 재료와 코어 레벨·재설정 재료를 얻는다. 신규 지역은 단순 상위 재료 사냥터뿐 아니라 새 사건과 수집 항목을 제공한다.

## 9. 아레나 상세

### 9.1 첫 버전 제안

실시간 대전 대신 **다른 유저가 등록한 방어 편성과 싸우는 비동기 대전**을 첫 구현안으로 한다. 이는 확정 사항이 아니다. 실시간 대전을 선택하면 매칭, 입력 지연, 재접속, 이탈 판정을 별도로 설계해야 한다.

- 세계관 명분: 공식 경기 또는 안전 장치가 있는 모의전. 구체적 제도는 미정.
- 맵: 좌우 대칭의 고정 경기장 1개. 장애물과 출발 위치도 고정.
- 흐름: 상대 확인 → 공격 편성 → 짧은 대치 → 전투 → 승패·기록 → 순위 반영.
- 공격·방어 모두 자동 스킬 판단을 적용하는 시험안으로 조작 비대칭을 줄인다.
- 방어 편성은 등록 당시 성장·장비·팀 공통 성장의 스냅샷을 사용하고 갱신 시점을 표시한다.
- 같은 캐릭터가 양쪽에 등장해도 정사상 분신 사건으로 설명하지 않는다.

### 9.2 시험 판정 규칙

90초 안에 상대 전멸 시 승리. 양측 동시 전멸은 무승부. 제한 시간 종료 시 생존 인원 → 생존 캐릭터별 잔여 HP 비율의 평균 순으로 판정하고, 완전히 같으면 무승부로 처리한다. 소환물·부활·이탈 시점은 전투 규칙 확정 후 별도 정의한다.

티어·레벨·코어·엑셀리티·전략을 그대로 적용하는 성장 반영형을 기준안으로 두되, 초반 테스트에서 내실 격차가 편성 대응을 압도하는지 확인한다. 정규화 대전을 추가할지는 그 결과로 결정한다.

### 9.3 매칭·보상

- 종합 전투력 대신 경기 등급·최근 전적과 신규 계정 보호 구간을 매칭 기준 후보로 사용한다.
- 상대 상세에서 편성과 주요 능력치를 확인할 수 있다. 합산 숫자를 숨겨 놓고 사실상 추천 전투력처럼 쓰지 않는다.
- 매일 순위 유지 때문에 과도한 반복을 요구하지 않도록 유효 보상 도전 수와 순위 갱신 구조를 분리해 검토한다.
- 주 보상은 명예, 프로필 장식, 외형, 범용 선택 재료다.
- 핵심 성장 재료를 최상위 순위에만 독점 지급하지 않는다.

## 10. 레이드 상세

### 10.1 첫 버전 제안

고정 전장 안에서 대형 보스와 싸우는 **개인 도전형 레이드**를 먼저 만든다. 실시간 협동·길드 공동 HP는 추후 별도 결정한다. 이름이 레이드라는 이유만으로 네트워크 협동을 확정하지 않는다.

- 명분: 특정 구역을 위협하는 대형 개체를 억제·토벌하는 작전.
- 최초 클리어: 실제 사건 해결 장면 제공.
- 반복: 동일 토벌의 재도전으로 표시. 매번 죽은 보스가 이유 없이 살아난다고 서술하지 않는다.
- 맵: 고정된 보스 위치, 위험 구역, 접근 경로. 맵과 카메라는 정확히 고정해 패턴 가독성을 우선한다.
- 보상: 토벌 보상과 실패 시 누적 성과 보상을 구분한다.

### 10.2 보스 R-01 — 이름·외형 미정

| 구간 | 행동 | 대응 | 연출 |
|---|---|---|---|
| 1페이즈: HP 100~70% | 단일 대상 강공격 + 전방 공격 | 생존 자원 사용, 위험 구역 대응 | 공격 방향과 예고를 명확히 표시 |
| 2페이즈: HP 70~35% | 보조 장치 활성화로 보스 강화 | 장치 우선 공격 또는 버티기 | 장치와 보스의 연결 이펙트 |
| 3페이즈: HP 35~0% | 기존 패턴 조합, 주기적 전역 공격 | 스킬·보호막·회복 사용 시점 조절 | 남은 시간과 위험 행동 강조 |

- 180초 종료 시 미토벌로 판정하되 성과를 기록한다.
- 장치 처리는 특정 캐릭터나 특정 효과만으로 가능하게 만들지 않는다.
- 페이즈 진입은 한 번만 실행한다. 큰 피해로 두 구간을 넘겼을 때는 최종 도달 페이즈로 이동하고 필수 연출 중복을 방지한다.
- 보스 무적 시간은 짧게 제한하고 전투 시간 집계 여부를 명시한다.
- 이동 조작이 없는 전투에서는 장판 회피를 생존 스킬·대상 선택 기믹으로 대체한다.
- 무한 부활·회복 편성이 토벌을 못 하더라도 성과 보상을 무한 누적하지 못하도록 유효 기록 기준을 둔다.

### 10.3 성과와 성장

주간 개인 최고 유효 피해 기록으로 단계 보상을 받는 방식을 제안한다. 보스 HP를 초과한 피해는 기록에서 제외하고, 동일 단계 보상을 중복 수령하지 않는다. 토벌 여부는 별도 표시한다.

전략의 단일 칸 성장 재료를 주 보상으로, 전체 칸 성장 재료를 장기 누적 보상으로 배치한다. 옵션 재설정 재료와 수치 성장 재료를 구분한다. 전략의 ‘100%’ 의미가 미정이므로 수치 상승량과 필요량은 확정하지 않는다.

### 11.2 경제 규칙

- 한 재료에 주요 획득처는 하나를 두고, 막힘 방지용 보조 획득처를 둔다.
- 기본 성장에 필요한 재료를 특정 PvP 순위나 레이드 토벌 성공에만 묶지 않는다.
- 돌파 확률이 100% → 80% → 50%로 낮아지고 이전 단계를 재시도하는 구조이므로, 실패 시 단계 유지·소모 규칙을 먼저 확정해야 일일 재료량을 계산할 수 있다.
- 일일 보상량은 `목표 성장 1회의 기대 소모량 ÷ 목표 소요일`을 기준으로 산정한다. 확률형 성장의 기대 소모량은 확정된 실패 규칙으로 계산한다.
- 새로운 캐릭터 육성은 개인 재료를 요구하지만 이미 얻은 팀 공통 성장을 다시 구매·해금하지 않는다.
- 공명은 시간 기준이므로 약한 적과 전투를 고의로 늘리는 행위가 유리해질 수 있다. 유효 전투 시간, 회차 상한, 종료 인정 조건을 출시 전 반드시 확정한다.
- 옵션 재설정으로 강해져야 같은 옵션 재료를 처음 획득할 수 있는 순환 관문은 피한다. 기본 획득 구간을 먼저 연다.

## 12. 상점 구성안

현금 가격과 상품 수량은 아직 제안하지 않는다. 재료 소모량과 획득량을 먼저 검증한다.

| 상점 | 판매/교환 후보 | 제한 | 제외할 것 |
|---|---|---|---|
| 일반 교환 | EXP, 일반 성장 비용, 공통 어빌리티 재료 | 일/주간 재고 시험 | 무한 차익 교환 |
| 의뢰 교환 | 돌파 재료, 어빌리티 특화 선택 상자 | 주간 제한 | 특정 특화 재료의 장기 품절 |
| 탐색 교환 | 엑셀리티 선택 재료, 코어 재설정 재료 | 누적 탐색으로 구매 | 스토리 코어 슬롯 직접 판매 |
| 아레나 교환 | 장식, 외형, 범용 선택 상자 | 시즌/주간 제한 | 필수 능력치의 상위 순위 독점 |
| 레이드 교환 | 전략 재설정, 단일/전체 성장 재료 | 누적 기여로 구매 | 토벌자만 기본 성장 가능하게 제한 |
| 유료 상점 | 외형·연출, 성장 보조 패키지 검토 | 경제 검증 후 결정 | 미확정 각성·100% 전략 수치의 선판매 |

모드마다 별도 화폐를 반드시 만들지는 않는다. 의뢰·탐색 교환을 공통 활동 화폐로 합칠지 첫 테스트에서 검토한다. 복잡성은 선택과 조합에서 만들고, 용도가 중복되는 화폐 수로 만들지 않는다.

### 13.2 반복 부담

- 짧게 접속한 날: 훈련 소탕 + 선택 의뢰 1회로 5~8분을 목표로 시험한다.
- 보통 접속한 날: 위 활동 + 도시탐색 1회로 12~20분을 목표로 시험한다.
- 스토리 진행·아레나 순위·레이드 기록 갱신은 추가 목표로 둔다.
- 매일 여섯 콘텐츠를 전부 완료해야 핵심 일일 보상을 받는 구조는 피한다.
- 일일 보상 놓침을 일부 주간 누적 목표로 보완할 수 있는지 검토한다.

## 15. 첫 제작 범위와 검증

### 15.1 제작 순서

1. **공통 전투 원형:** 승인된 SD 캐릭터로 한 전장에서 이동·공격·스킬·피격·결과를 연결한다. 카메라와 조작 방식 확정이 우선이다.
2. **스토리 S1-04:** 도착 → 방어 전투 → 기록 발견 → 결과까지 구현해 이야기와 전투 연결을 확인한다.
3. **현상수배 B-01 / 훈련 T-02:** 같은 엔진으로 다른 목표와 평가를 만들 수 있는지 검증한다.
4. **도시탐색 1구역:** 분기·비전투 사건·HP 유지·귀환을 연결한다.
5. **아레나 1맵 / 레이드 1보스:** 고정 전장과 결과 판정, 성장 격차를 시험한다.
6. **보상·상점 연결:** 실제 획득량을 바탕으로 성장 기간을 조정한 후 반복 플레이를 검증한다.

첫 버전에서 모든 캐릭터의 모든 모션·전용 사건을 동시에 제작하지 않는다. 대표 역할을 가진 소수 캐릭터로 공통 규격을 검증하고 11명으로 확장한다. 구체적인 선정은 능력·외형 시트 확인 후 한다.

### 15.2 합격 기준

| 영역 | 확인할 질문 | 불합격 신호 |
|---|---|---|
| 개연성 | 전투 전 왜 싸우는지, 끝난 뒤 무엇이 바뀌는지 설명 가능한가 | 모든 입장이 출동 대사 한 줄로 동일 |
| 콘텐츠 구분 | 동일 편성으로도 모드마다 판단이 달라지는가 | 맵과 적 체력만 다름 |
| 캐릭터 | 콘텐츠를 바꿔도 같은 얼굴·무기·비율·성격인가 | 장면마다 재생성된 다른 외형 |
| 현상수배 | 의뢰 조건이 실제 행동에 영향을 주는가 | 모든 조건을 무시하고 전체 공격으로 해결 |
| 훈련 | 원하는 재료를 예측 가능하게 얻는가 | 낮은 난도에서 필수 재료 획득 불가 |
| 탐색 | 조사와 귀환 선택의 결과가 다른가 | 모든 선택이 같은 전투·보상 |
| 아레나 | 결과를 상대 편성·행동으로 이해할 수 있는가 | 설명 없는 성장 격차만 승패 결정 |
| 레이드 | 패턴 학습이 다음 기록 개선으로 이어지는가 | 동일 시간 동안 HP만 깎음 |
| 경제 | 특정 실패·재료 운 때문에 진행이 과도하게 막히지 않는가 | 보조 경로도 없는 확률 관문 |
| 반복 | 첫날 이후 설명 장면이 부담이 되지 않는가 | 같은 대사를 매회 강제 |

수집할 기록: 모드별 완료율, 평균 시간, 실패 원인, 의뢰 선택률, 탐색 조기 귀환율, 전투/비전투 시간, 재료 부족으로 멈춘 성장 단계, 캐릭터 사용률, 무과제 반복 시간. 수치는 테스트 뒤 정하며 목표치가 확정된 것처럼 제시하지 않는다.

## 17. 참고 게임에서 확인한 구성과 적용 범위

아래는 앞선 조사에서 확인한 사례의 요약이다. 어킹의 상세 규칙은 이 문서의 제안이며, 참고 게임이 똑같은 규칙을 사용한다는 뜻이 아니다. 자료 확인일은 2026-10-15이며 운영 업데이트에 따라 달라질 수 있다. 커뮤니티 위키·가이드가 포함되어 있어 출시 전 세부 구현을 대조할 때는 실제 플레이를 추가 확인한다.
