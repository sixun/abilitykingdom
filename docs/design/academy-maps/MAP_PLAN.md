# 어빌리티킹덤 스토리 모드 — 아카데미 맵 기획

## 1. 목표와 현재 범위

현대도시의 능력자 아카데미를 2.5D 쿼터뷰로 탐색합니다. 하나의 맵 안에서는 상하좌우 및 대각선으로 이동하고 카메라가 연속 추적합니다. 다른 맵으로 갈 때 문·출입구·포탈을 통해 전환합니다.

현재 제공하는 배경은 정문 진입 구역과 수업동 연결 복도, 총 2개 맵입니다. 각 맵의 4장은 서로 겹치는 카메라 구간입니다. 화면마다 로딩하거나 새로운 방으로 전환하지 않습니다.

## 2. 비주얼 기준

- 제공 이미지의 쿼터뷰, 재질감, 조명, 색조를 유지합니다. 평면 탑뷰나 저해상도 픽셀 타일맵으로 바꾸지 않습니다.
- 현대 능력자 아카데미이며, 일반 대학 캠퍼스나 중세 왕궁으로 재해석하지 않습니다.
- 아이보리 석재, 짙은 목재·철제, 남색과 절제된 금색 문장, 유리와 현대식 출입 설비가 기본 분위기입니다.
- 가로 16:9를 기준으로 합니다. 맵 전체를 화면에 축소해서 넣지 않고 일부를 보여줍니다.
- 세렌 등 기존 캐릭터 에셋을 사용합니다. 캐릭터 비율은 승인된 참고 화면의 느낌을 기준으로 조정하며, 과도하게 작아지지 않도록 합니다. 초기 비교 기준은 화면 높이의 약 21~24%이며 실제 배경과 함께 보고 조정합니다.
- 이동거리는 맵의 범위와 경로로 확보합니다. 화면을 줌아웃하거나 빈 바닥 면적만 늘려 해결하지 않습니다.

## 5. 게임 적용 기준

### 배경과 카메라

권장 방식은 4개 화면을 공통 좌표에 복원해 맵당 배경 1장으로 쓰는 것입니다. 제공 스크립트 또는 엔진의 단순 합성으로 처리합니다. 다른 방식으로 청크를 사용해도 좌표와 스케일이 같아야 하며 겹치는 영역을 이중 블렌딩하지 않습니다.

배경 좌표의 원점은 좌상단, X는 오른쪽, Y는 아래쪽입니다. 이는 이미 투영된 그림의 좌표입니다. 쿼터뷰처럼 보이게 하려고 배경에 별도의 등각 투영을 다시 적용하지 않습니다.

카메라는 플레이어를 따라가며 경계에서 제한합니다. 검은 빈 공간이 노출되거나 청크 경계에서 점프하지 않아야 합니다. 초기 뷰포트는 각 크롭 크기 부근에서 시작해 캐릭터와 함께 조정합니다. UI는 화면 좌표에 고정합니다.

현재 크롭 기준 전체 배경은 가로·세로 각각 약 1.6화면 범위입니다. 4개 화면이 겹치므로 서로 독립된 4화면 넓이의 맵은 아닙니다. 긴 탐색 구간을 원하면 이후 배경 자체의 확장이 필요합니다.

### 이동과 충돌

기존 이동·입력 시스템을 재사용합니다. 발 위치를 이동 기준점으로 잡고, 벽·문기둥·화단·벤치·계단 측벽에는 충돌 영역을 지정합니다. 바닥에 보이는 빈 영역이라도 실제로 연결되는 보행면인지 확인합니다. 충돌 데이터는 이미지와 분리된 편집 가능한 폴리곤 또는 저장소의 기존 데이터 형식으로 관리합니다.

계단은 우선 단일 평면의 이동 경로로 처리할 수 있습니다. 높이 변경이나 층간 연결이 필요하면 기존 시스템에 맞춰 전환 영역으로 구현합니다. 그림 속 계단만으로 자동 높이 처리가 된다고 가정하지 않습니다.

### 캐릭터 가림과 깊이

캐릭터와 NPC는 발의 Y좌표를 기준으로 정렬합니다. 단일 평면 배경만으로 기둥·화단 뒤로 들어가는 가림 효과가 생기지는 않습니다. 필요한 전경 오브젝트는 별도 레이어 또는 마스크로 분리해야 합니다. 분리하지 못한 구조물 뒤는 충돌로 진입을 제한하고 남은 한계를 명시합니다.

### 상호작용과 맵 전환

문·출입구 주변에 전환 영역을 지정하고 목적지 맵·도착 위치·바라보는 방향을 데이터로 저장합니다. 전환 직후 다시 포탈에 걸리는 루프를 막습니다. 배경에 그려진 게시판·안내실은 별도 상호작용 영역을 붙여야 동작합니다. 기존 NPC·대화 시스템을 우선 연결하며 새 UI나 임의의 전투 기능을 추가하지 않습니다.

## 6. 해상도 및 현재 에셋 한계

현재 배경 원본은 맵당 1672×941이고 개별 화면은 약 1040×585입니다. 확대 표시하면 디테일 선명도가 떨어질 수 있으며 4K 제작 에셋이 아닙니다. 단순 업스케일은 원래 없던 디테일을 복구하지 않습니다. 우선 구조·이동·아트 적합성을 확인한 후 최종 표시 배율에 맞는 고해상도 배경과 전경 레이어를 제작합니다.

이미지 8장 사이의 겹침 일치는 보장되지만, 실제 게임의 충돌·동선·렌더링은 아직 검증되지 않았습니다. AI 이미지의 구조적 오류가 있으면 적용 과정에서 별도 기록합니다.

## 7. 적용 완료 확인

- 2개 맵이 올바른 배율과 쿼터뷰로 표시되는지 확인합니다.
- 상하좌우·대각 이동, 충돌 경계, 좁은 길 통과를 확인합니다.
- 카메라 이동 시 지형 이음새·반복·점프·화면 밖 빈 공간이 없는지 확인합니다.
- 캐릭터가 벤치·화단·벽을 관통하거나 부적절하게 앞에 표시되지 않는지 확인합니다.
- 맵 전환 후 올바른 위치에 도착하고 재진입 루프가 없는지 확인합니다.
- 가로 16:9 및 실제 대상 기기 비율에서 화면·입력·기존 UI를 확인합니다.
- 제공되는 빌드·타입 검사와 관련 기존 테스트를 실행하고, 실제로 확인한 항목과 미확인 항목을 구분해 보고합니다.
