# 어빌리티킹덤 아카데미 맵 적용 패키지

8장의 이미지는 **정문 1개 맵의 4개 카메라 화면 + 연결 복도 1개 맵의 4개 카메라 화면**입니다. 8개의 독립 맵이 아닙니다.

- `MAP_PLAN.md`: 세계관·맵 구성·구현 기준
- `CLAUDE_TASK.md`: 클로드에게 전달할 적용 요청문
- `maps/`: 원본 그대로의 PNG 8장
- `map_manifest.json`: 이미지 크기와 공통 맵 좌표계의 배치 좌표
- `reconstruct_maps.py`: 겹침 일치를 검증하고 각 맵을 하나의 배경으로 복원하는 선택적 도구

먼저 `CLAUDE_TASK.md`와 `MAP_PLAN.md`를 읽고 저장소 구조를 확인해 적용합니다. 이미지에는 UI와 캐릭터가 없습니다. 배경에 그려진 문·계단·화단은 자동으로 게임 오브젝트가 되지 않으므로 충돌·상호작용·전경 가림 데이터를 별도로 설정해야 합니다.

이미지 8장의 겹치는 부분은 같은 원본에서 추출되었습니다. 이 패키지의 좌표는 확인된 배경 좌표이며, 충돌 경계·NPC 위치·포탈 위치는 구현 시 그림과 대조해 지정해야 합니다.
