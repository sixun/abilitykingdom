## 0. 최우선 지시

**첨부된 첫 번째 이미지를 디자인 기준으로 삼아 기존 앱의 '로비 좌측 상단 프로필' 클릭 시 열리는 16:9 가로 전체화면을 구현해 주세요.** 이것은 새로운 로비나 캐릭터 육성 화면이 아니라 **플레이어(팀장)의 계정 프로필 / 신분증 / 대표 팀원 전시 화면**입니다.

1. 먼저 프로젝트의 현재 라우팅·UI 프레임워크·상태 관리·데이터 모델·에셋 구조를 확인하고 기존 코드를 최대한 재사용하세요. 프로젝트에 없는 API/테이블/필드는 실제 데이터인 것처럼 단정하거나 임의 생성하지 마세요.
2. 첨부 이미지는 **최종 목표 시각 레퍼런스**입니다. 그대로 게임에 배경 한 장으로 합성해 인터랙션을 흉내 내지 말고, 배경/물체/신분증/텍스트/카드/버튼 등 필요한 부분을 실제 UI 레이어로 구현하세요. 참고 이미지 자체를 개발자가 임의로 잘라 에셋화할 수 있는지 검토하되, 글자가 박힌 원본 스크린샷을 그대로 UI에 사용하는 것은 피하세요.
3. 실제 데이터 연동이 아직 없다면 **mock 데이터와 실제 저장/조회 기능을 엄격하게 구별**하고, 구현 내역에 연결되지 않은 항목을 보고하세요.
4. 기존 로비·다른 화면 및 디자인을 불필요하게 변경하지 마세요. 작업 완료 후 변경 파일, 테스트 결과, 미연동 항목을 보고하세요.

## 1. 화면 목적과 세계관

- 사용자 = **팀장(플레이어)**. 수집한 캐릭터들은 **팀원**이며, 팀장의 기본 외형과 독립적으로 운영합니다.
- 화면 콘셉트: `CITY RESPONSE UNIT / A7` 지휘 조직의 **실물 대원증 + 작전 기록 열람 단말기**.
- 지휘실 책상, 목걸이 클립, 바코드, 도장, 서명, 문서, 폴라로이드, 스티커 같은 **물성이 느껴지는 그래픽**이 시안의 핵심입니다. 평범한 반투명 사각 카드 대시보드로 단순화하지 마세요.
- 특정 팀원 캐릭터가 책상에 앉아 있는 전용 일러스트는 **사용하지 않음**. 모든 계정에 공통 적용 가능한 A7 집무실/데스크 배경을 사용.
- 레이아웃 기준: **가로 16:9**. 원본 시안 해상도 1672×941. 작은 가로 해상도에서도 요소가 잘리지 않도록 상대적인 배치 및 폰트/간격 스케일링을 적용.

## 2. 화면 구조 (확정 시안 기준)

### 좌측 약 45% — 대형 실물 대원증

- 상단 뒤로가기 화살표 / 화면 제목 `팀장 정보` (원본 시안 제목 `팀원 정보`는 잘못된 표현이므로 수정).
- 책상에 놓인 커다란 카드·파일 클립·소품·사진을 가진 신분증 비주얼.
- 대원증: `CITY RESPONSE UNIT`, `A7`, 프로필 이미지, 팀장 닉네임, `LV.`, `UID`, `소속`, 직책 `팀장`, 바코드, 서명 형식의 장식, 자기소개.
- 길드 가입 시 `길드 엠블럼 + 길드명 + 길드 내 직책` 표시. 미가입 시 미가입 상태와 길드 탐색 진입 제공.
- **대원증 중앙 인물사진은 특정 수집 캐릭터 고정이 아니라 아래 3절의 '플레이어 프로필 아이콘'을 표시**.
- 카드 주변 폴라로이드, 메모지, A7 코인/도장 등의 소품은 레퍼런스의 특징이므로 우선 보존하되 읽기 쉬운 구조 유지. 이 소품들은 필수 기능 컨트롤이 아닌 장식.

### 우측 상단 — 네비게이션

- 레퍼런스 톤의 가로 탭: `프로필`(기본 선택) / `상세 정보` / `작전 기록` / `업적` / `컬렉션`.
- 실제 기존 앱 기능이나 라우트가 존재하는지 확인하고 연결. 없는 탭은 미구현 상태를 명확히 처리; 작동하지 않는 버튼을 정상 기능처럼 보이게 하지 말 것.

### 우측 상부 — 대표 팀원 5장

- **최우선 가시 영역**. 시안과 같이 가로로 나란한 세로형 캐릭터 카드 5장을 **충분히 큰 크기로 유지**.
- 각 카드: 실제 캐릭터 초상화, 이름, 관련 표시값(해당 게임 캐릭터 레벨·티어·등급 등 기존 UI 규칙에 부합하는 것).
- **팀장 LV와 팀원 레벨은 별도**. 카드에 팀장 LV를 복사해 표시하지 말 것.
- 팀원 5명은 플레이어가 직접 골라 전시하는 **대표 팀원 슬롯**. 전투 편성과는 분리된 설정이며, 설정 변경 시 전투 편성은 바뀌지 않음.
- 미설정 슬롯은 명확한 플레이스홀더, 선택 진입. 레퍼런스의 `5/5`는 설정된 수/최대 수.
- 카드 디자인에 없는 별도 숫자/아이콘을 과하게 추가하지 말 것. UI 밀도 증가 방지.

### 우측 중단 — 대표 설정

- 세 영역: `대표 칭호` / `프로필 배경` / `길드 엠블럼`(길드 엠블럼이 계정 장착 요소인지 길드 공용 로고인지 기존 설계 확인).
- 현재 장착값의 **미리보기**가 먼저 보이고, 누르면 선택 화면 또는 패널로 이동.
- 기본 화면에 모든 후보 리스트를 펼쳐놓지 말 것.
- 프로필 배경은 **개인 프로필 전시 배경**과 **공통 A7 지휘실 UI 배경**을 개념적으로 분리해야 함. 전체 지휘실 분위기가 프로필 아이템마다 훼손되지 않도록 관리.

### 우측 하단 — 활동 요약

- `완료한 작전` / `도시 탐색` / `레이드 참여` / `현상수배 처리` 같은 대표 수치를 **한 줄 요약**.
- 시안의 `32`, `61%`, `12회`, `47회` 등은 모두 **디자인 예시 숫자**이며 실제 사용자 데이터로 가정하지 말 것.
- 상세 통계/타임라인/메달 목록은 상세 탭에서 열람. 메인에 모두 펼치지 않아 과밀화를 방지.

## 3. 프로필 이미지 — 최종 권장 UX (중요)

### 역할 분리

| 항목 | 의미 | 설정/표시 규칙 |
|---|---|---|
| **팀장 기본 아바타** | 플레이어 자신의 세계관상 지휘관 상징 | 최초 설정 시 **남성형/여성형** 중 선택 가능. 얼굴 윤곽이 모호하거나 일부 가려진 기본 일러스트도 가능. 플레이어의 실물 사진을 요구하지 않음 |
| **프로필 아이콘** | 타인에게 보이는 계정 대표 이미지 (LoL 소환사 아이콘 방식) | 기본 팀장 아바타, 해금된 아이콘, 보유한 팀원의 프로필 초상화 등 **장착 가능한 아이콘** 중 선택 |
| **대원증 사진** | 위 UI의 인물사진 부분 | **현재 장착된 프로필 아이콘과 동기화**. 전용 포즈·전용 신분증 일러스트를 매 캐릭터마다 제작하지 않음 |
| **대표 팀원 5명** | 좋아하는 캐릭터 전시 | 프로필 아이콘/팀장 성별/전투 편성과 독립적으로 변경 |

### 초기 설정 / 변경 흐름

1. 신규 플레이어에게 기본 **남성형 팀장 아바타**와 **여성형 팀장 아바타**를 제공(초기 선택 흐름을 만드는 것이 기존 온보딩에 과한 변경이면 프로필 진입 시 변경 가능하도록 처리).
2. 프로필 아이콘은 기본으로 선택한 팀장 아바타가 적용되며, 이후 프로필 편집에서 자유롭게 교체.
3. 수집한 캐릭터의 **보유/해금 가능한 초상화 리소스**는 아이콘 후보에 포함할 수 있음. 게임에 이미 존재하는 리소스를 우선 사용.
4. 아이콘을 바꾸면 **로비 좌측 상단 원형 프로필 이미지 + 대원증 사진 + 타인에게 보여주는 계정 아이콘**이 같은 장착값을 참조.
5. 팀장 기본 성별 선택과 아이콘은 **독립 속성**. 남성형 팀장으로 설정해도 여성 팀원 아이콘 장착 가능. 대표 팀원을 바꿔도 프로필 아이콘이 자동 변경되지 않음.
6. 프로필 편집에서 미보유 아이콘은 잠금과 해금 조건을 표시. 미구현 보상·구매 조건은 임의 생성하지 않음.
7. 저장 시 계정 기준으로 유지되고 재접속 후 복원되어야 함. 서버 저장 설계가 없으면 임시 클라이언트 상태임을 반드시 명시.

### 시안에 붙인 얼굴 사진의 의미

참고 이미지의 검은 머리 여성 사진은 **고정된 세계관 주인공 일러스트가 아닙니다**. 현재 프로필 아이콘의 **예시**로 취급합니다. 실제 구현에서는 선택된 기본 팀장 아바타 또는 장착한 소환사 아이콘이 들어갑니다. `image(20261020-131328).png`는 이 사진 영역을 식별하기 위한 확대 참고 이미지이며, 모든 이용자에게 동일하게 강제할 에셋은 아닙니다.

## 4. 데이터 연결 지침

먼저 기존 계정 테이블/프로필 설정/캐릭터 보유 목록/길드/작전 통계 API의 유무를 조사하고 사용 가능한 필드를 매핑하세요. 다음은 **개념 필드명**으로 스키마를 강제하지 않습니다.

- Account: `userId`, `nickname`, `commanderLevel`, `commanderAvatarType`, `equippedProfileIconId`, `bio`, `equippedTitleId`.
- Representative display: 최대 5개의 `characterId` 순서 목록(기존 전투 편성값과 별도).
- Guild: `guildId`, `guildName`, `guildEmblem`, `guildRole`, 가입 여부.
- Profile decoration: 배경, 칭호, 엠블럼 등 **실제 해금/장착 내역**.
- Activity: 작전 완료 수, 도시 탐색률, 레이드 참여 횟수, 현상수배 처리 횟수 등 기존 집계가 있다면 재사용.
- 다른 사람의 프로필 열람 시에는 보기 전용이며 편집 아이콘을 숨겨야 함.

## 5. 인터랙션 요구사항

- 로비 좌측 상단 프로필 클릭 → **가로 전체 화면** 진입, 뒤로가기 → 직전 로비 복귀.
- 대원증 사진 또는 편집 버튼 → 프로필 아이콘 선택. 자기소개/닉네임 등의 편집 가능 여부는 기존 계정 정책에 따름.
- 대표 팀원 슬롯 클릭 → 해당 슬롯에 장착할 **보유 캐릭터 선택**. 저장 후 5개 카드 표시 갱신. 기존 게임의 캐릭터 고유 명칭/초상화 사용.
- 길드 정보 클릭 → 기존 길드 상세 또는 길드 탐색 UI. 길드 기능 출시 전에는 가짜 가입 상태를 노출하지 말 것.
- 칭호/배경/엠블럼 → 각 장착 UI로 이동. 실제 선택한 장식이 카드에 반영됨.
- 태블릿/PC형 폭과 휴대폰의 16:9 가로 화면에서 텍스트 절단, 터치 타깃 겹침, 카드 가독성을 점검.

## 6. 디자인 유지 및 금지사항

**유지**

- 실물 대원증 비주얼(집게, 종이 질감, 서명, 바코드, 스탬프).
- 지휘실 배경의 원근감 및 도시 대응본부 A7 브랜딩.
- 대표 팀원 5장 큰 세로 카드. 유저가 강조한 핵심이므로 축소 금지.
- 복잡한 정보는 우측의 계층적 반투명 UI에 적절히 분리.
- 길드 로고와 길드 소속이 플레이어의 지위를 강화하도록 시각적으로 연계.

**금지**

- 특정 캐릭터의 책상 착석 일러스트를 필수 조건으로 만들기.
- '팀장 프로필'을 '전투용 팀원 육성'과 혼동하는 정보/수치 배치.
- 레퍼런스 전체를 통짜 이미지로 보여주고 그 위에 투명 클릭 영역만 올리기.
- 시안 예시 수치를 실제 값처럼 하드코딩하기.
- 존재하지 않는 API/DB/길드/칭호 보유 정보를 정상 연동된 것처럼 보고하기.
- 기존 로비에 영향을 주는 불필요한 리팩터링, 임의 배포.
