# 어빌리티킹덤 웹 프로토타입 (v0.4 · 원본 화면 재현 + 대기 모션)

v0.2에서는 `Ability-Kingdom-Complete-Assets` 패키지(CLAUDE-START-HERE.md)대로 **로비·영입·편성 세 화면을 원본 시안 그대로 다시 만들었습니다.**
새 디자인으로 해석하지 않았습니다. 원본 조각(Original-Pixel-Slices)을 layout.json 좌표 그대로 배치하고, 동적으로 바뀌는 부분만 복원 배경·복원 캐릭터·글자 없는 SVG 스킨과 실제 텍스트로 덮습니다.

v0.3에서 **역 승강장 로비**(Station-Lobby 패키지)를 두 번째 로비 테마로 추가하고, **캐릭터 상세**를 지안 상세 원본(Jian-Detail 패키지)대로 다시 만들었습니다. 기존 소파 로비는 그대로 두고 버튼으로 오갑니다.

공개 링크: https://sixun.github.io/abilitykingdom/

## 실행법

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ 생성 (정적 호스팅 가능, 상대 경로)
npm run test:e2e     # dev 서버 실행 중에 브라우저 자동 검증 (Playwright)
```

- 바로가기: `?screen=lobby`, `?screen=recruit`, `?screen=formation`, `?screen=characterDetail`
- 로비 테마: 소파 로비 상단 **[역 로비]** 버튼 ↔ 역 로비 상단 **[카페 로비]** 버튼(두 로비의 메뉴에도 있음). 선택은 저장됩니다.
- 진행 데이터는 브라우저 localStorage에 저장됩니다. 설정 > 로컬 데이터 초기화로 처음 상태(원본 시안과 같은 값)로 돌립니다.
- 에셋 재생성: `python3 tools/build_ref_assets.py`(원본 조각 → 무손실 WebP + layout JSON), `python3 tools/fit_restored.py`(복원 캐릭터를 원본 실루엣에 맞춘 위치·배율 계산), `python3 tools/build_ref2_assets.py`(역 로비·지안 상세 조각), `python3 tools/make_textless.py`(원본에서 글자·알림만 지운 근사 패치), `python3 tools/build_detail_art.py`(상세 임시 아트 배치값)

## 재현 방식

| 항목 | 방식 |
| - | - |
| 캔버스 | 로비 1456×818, 영입·편성 1456×819 고정 좌표. 화면 크기에 맞춰 캔버스 전체에 **같은 배율 하나만** 적용하고 남는 영역은 검정(레터박스). 개별 요소 늘이기·cover 없음 |
| 기본 표시 | 원본 조각 88개(로비 23 · 영입 25 · 편성 40)를 원래 좌표에 배치. PNG를 픽셀 동일한 무손실 WebP로 변환(용량 절감) |
| 동적 표시 | 상태가 원본 시안 값과 같으면 원본 조각 그대로. 바뀐 영역만 조각을 숨기거나 스킨+HTML 텍스트로 덮고, 비는 자리는 복원 배경으로 채움 |
| 버튼 | 원본 조각 경계에 맞춘 투명 `<button>`(접근성 이름 포함). 누름·포커스는 CSS로 표시 |
| 복원 캐릭터 | 원본 조각을 그대로 복사하지 않고, 원본 실루엣 마스크와 겹침이 가장 큰 배율·위치를 계산해 얼굴·어깨 위치를 맞춤(`ref-fit.json`). 원본의 하체 가림(전경·하단 바)도 유지 |

## 원본 비교 (docs/review/)

브라우저(Chromium, 원본과 같은 크기)로 렌더한 결과를 원본과 픽셀 비교했습니다.

| 화면 | 기본 상태 픽셀 일치 | 비교 이미지 | 동적 변경 예시 |
| - | - | - | - |
| 편성 | 100.00% | compare-formation.jpg | dynamic-formation.jpg (3번 슬롯 교체·팀 전환) |
| 영입 | 100.00% | compare-recruitment.jpg | dynamic-recruitment.jpg (다른 배너 선택) |
| 로비(소파) | 99.41% | compare-lobby.jpg | dynamic-lobby.jpg (재화 변화), dynamic-lobby-theme-button.jpg |
| 로비(역) | 97.76% | compare-station.jpg | (기본 상태에 이미 동적 값 포함) |
| 캐릭터 상세 | 96.15% | compare-detail.jpg | dynamic-detail-yujin.jpg, dynamic-detail-skills.jpg, dynamic-detail-unowned-gear.jpg |

차이가 나는 자리는 모두 의도한 것입니다.
- 소파 로비: 원본에 없는 **더보기 메뉴**·**[역 로비]** 버튼.
- 역 로비: 실제 데이터와 원본 그림의 값이 달라 바꾼 칸(다이아 830→12800, 크레딧 598K→388K, 프로필 Lv.32 지안→Lv.15 마유, 메인 목표 7-21→1-1, 출석 남은 시간), 실제 상태가 없는 알림 표시 제거(프로필 N, 훈련·편성·영입 점, 도시 탐색 N, 스토리 !), 받을 우편이 있어 우편 점 추가, **[카페 로비]** 버튼.
- 캐릭터 상세: 원본 초상 02~06은 어떤 캐릭터인지 확정할 수 없어 보유 캐릭터 초상으로 바꿈, 목록 처음이라 앞으로 화살표 비활성 표시, 지안이 현재 로비 캐릭터라 SET AS LOBBY → LOBBY ACTIVE.

- 자동 편성(임시 규칙: 전투력순), 초기화(마지막 저장 상태로), 저장
- 팀 전투력 자동 계산(원본 4명 기준 24,680이 나오도록 계수 조정)

**정적인 것**
- 배경과 상단 장식
- 하단 바의 원본 아이콘 그림
- 원본 4명의 대기 자세(원본 조각은 한 장 그림이라 움직이지 않음)

**복원·임시로 원본과 달라지는 것**
- 교체되어 원래 자리가 빈 곳은 AI 복원 배경으로 채웁니다. 건물·바닥 세부가 원본과 다릅니다.
- 지안·유진·하린·도윤이 다른 슬롯으로 옮겨지면 AI 복원 전신을 씁니다. 얼굴·옷 주름 세부가 원본과 다릅니다.
- 세인·나린·리온·서하는 복원 전신이 없어 v0.1의 임시 AI 컷아웃을 씁니다. **그림체가 맞지 않습니다.**
- 이름표·팀 탭·전투력은 바뀔 때만 글자 없는 SVG 스킨과 실제 텍스트로 덮습니다. 스킨은 원본을 단순화해 새로 그린 것이라 질감이 원본과 다릅니다.
- 추가 요소: 저장 전 변경 표시, 리더 지정 팝업, 확인 대화상자. 원본에 없어 v0.1 스타일로 그렸습니다.

- 지안 외 캐릭터의 영문 소속·소개 문구와 CRIT·SPEED 값은 샘플입니다.
- SKILLS·GEAR 내용 화면은 확정 시안이 없어 기존 기능을 원본 행 모양으로 넣은 임시 구성입니다.
- 능력치 체계: 지안 Lv.40이 원본 값(18600/3240/1280)이 되도록 샘플 수치를 Lv.40 기준으로 바꾸고, 편성 팀 전투력 24,680이 유지되도록 배율을 다시 맞췄습니다(밸런스 미확정).

- **오프닝 노래**: 사용자 제공 "Four-Note Storm"(40초, MP3 192kbps, 표지 이미지만 제거). TAP TO START를 누른 순간 노래가 시작되고 0.6초 뒤 영상이 시작됩니다. 영상 원래 소리와 노래를 겹쳐 재생하고(둘 다 배경음 볼륨), 건너뛰기·화면 전환 복귀 때도 노래 = 영상 + 0.6초 간격을 유지합니다. 타이틀에서 오래 머물면 노래를 반복하고, 입력해서 로비로 넘어가면 0.45초 동안 줄이며 끕니다. 브라우저가 소리를 막으면 SOUND ON 버튼이 나옵니다.
- **없는 것**
  - 캐릭터 입장 영상
  - 리깅: 파츠 분리 PSD, Live2D, Spine
  - 표정별 프레임
  - 정밀 전경 가림 마스크와 그림자

  지금 캐릭터 "움직임"은 교체 시 정지 그림이 들어오고 나가는 CSS 연출뿐입니다.

## 대기 모션 (v0.4, Ability-Kingdom-Motion-Assets)

| 화면 | 적용 |
| - | - |
| 소파 로비 | 장면 = UI 없는 지안 소파 영상(motion/sofa). 원본 UI 조각은 배경을 걷어낸 매트로 위에 올림. 감상 모드는 같은 영상 그대로 UI만 숨김 |
| 역 로비 | 장면 = 지안 역 로비 영상(motion/station). 카드·아이콘·하단 메뉴 매트, 알림 표시는 상태에 따라 '표시 있는 판/지운 판'을 골라 씀 |
| 캐릭터 상세(지안) | 원본에서 인물을 지운 배경판 + 배경 제거 대기 영상(motion/detail) + 원본 UI. 진입: 사선 마스크 → 인물 → 이름 → 능력치 순차. 탭을 누르면 선택 배경이 180ms 이동 |
| 영입(리온 배너) | 원본 장면에서 리온을 지운 배경판(빈 자리는 복원 옥상 배경) + 리온 대기 영상(motion/recruit). 배너 진입: 사선 wipe → 리온 → 제목 안착 → 하단 클로즈업. REC 점 1.6초 점멸, 파형 막대(장식, 소리 분석 아님), ON AIR 광택 흐름 |

- 진입(로비): 장면 0ms → 상단 80 → 좌 130 → 우 170 → 하단 220ms, 그룹마다 240ms 이동+페이드. 버튼은 같은 그룹 안에서 함께 움직여 보이는 위치와 누르는 위치가 같습니다.
- 재생: 소리 없음·반복·인라인. 맨 위 화면일 때만 재생하고 다른 화면으로 가거나 앱이 백그라운드로 가면 멈춥니다. 동작 줄이기·재생 실패 시 정지 포스터.
- 영상 가공(`tools/build_motion_assets.py`): 반복 이음새 4프레임 크로스페이드, 캐릭터 가장자리 마젠타 번짐 제거·1px 알파 수축, 1080×1080 VP9 알파. 로비 영상은 VP9 WebM + H.264 MP4.
- 배치값(`src/game/data/motion-fit.json`): 영상 첫 프레임을 원본 화면에 SIFT로 맞춘 배율·위치(얼굴 기준 오차 2~4px). 역 로비는 위쪽 빈틈이 없도록 15px 올림.

**한계**
- 사파리·아이폰(앱 포함)은 VP9 알파 영상을 투명하게 재생하지 못해 **상세·영입 캐릭터는 정지 포스터**로 보입니다(로비 영상은 재생). iOS용 HEVC 알파 영상은 Mac에서 만들어야 합니다.
- 상세 배경의 큰 'JIAN' 글자 느린 이동은 **하지 않았습니다**. 원본 배경이 한 장으로 합쳐져 있어 글자만 따로 움직일 수 없습니다(분리된 배경 그래픽 필요).
- 인물을 지운 자리(인페인트)는 머리카락이 움직일 때 가장자리에 흐린 자국이 조금 보일 수 있습니다.
- 매트는 원본과 UI 없는 복원 배경의 차이로 만든 근사입니다. 반투명 카드(훈련 등) 안쪽에는 옛 배경이 구워져 있습니다.
- 로비 영상은 지안 전용입니다(다른 캐릭터 로비 장면 없음).

## 앱 빌드 (아이폰·안드로이드)

내려받기: https://github.com/sixun/abilitykingdom/releases/latest (안드로이드 APK, 아이폰 서명 없는 IPA·시뮬레이터용)

웹 빌드를 [Capacitor](https://capacitorjs.com) 8로 감싼 앱입니다. **테스트 기간에는 앱이 공개 웹(https://sixun.github.io/abilitykingdom/)을 직접 불러옵니다.** 웹만 배포하면 설치된 앱도 다음 실행 때 바뀌므로 앱을 다시 빌드할 필요가 없습니다(GitHub Pages 캐시 때문에 최대 10분 정도 늦을 수 있음). 앱 아이콘·이름·권한처럼 앱 자체를 바꿀 때만 다시 빌드합니다.
- 인터넷이 없으면 앱 안의 안내 화면(`native-shell/offline.html`)이 나옵니다.
- 앱스토어 정식 출시 전에는 `capacitor.config.ts`의 `server` 항목을 지우고 `webDir`을 `dist`로 바꿔 웹 파일을 앱 안에 넣는 방식으로 되돌려야 합니다(웹사이트를 감싸기만 한 앱은 심사에서 거절될 수 있음).

| 항목 | 값 |
| - | - |
| 앱 이름 / ID | 어빌리티킹덤 / `com.wakamonlabs.abilitykingdom` (임시) |
| 버전 | 0.4.1 (빌드 6) — 앱 껍데기 버전. 화면 내용은 웹 배포를 따름 |
| 아이콘 | 리온 전신 이미지에서 얼굴 쪽을 잘라 만든 임시 아이콘(`app-icons/`, `npm run icons`로 재생성). 안드로이드는 적응형 아이콘 |
| 화면 | 가로 고정, 상태바·내비게이션 바 숨김, 검정 시작 화면 + 아이콘 |

**안드로이드**
- `npm run android:apk` → `android/app/build/outputs/apk/debug/app-debug.apk` (Android SDK·JDK 21 필요, 약 6MB)
- 저장소의 공용 디버그 키(`android/app/debug-shared.keystore`)로 서명합니다. 어디서 빌드해도 같은 키라 새 버전을 덮어 설치할 수 있습니다. **Play 스토어 출시에는 별도 비공개 릴리스 키가 필요합니다.**
- 설치: APK를 휴대폰에서 열고 "출처를 알 수 없는 앱 설치"를 허용합니다.

**아이폰**
- 아이폰 앱은 Mac의 Xcode로만 빌드할 수 있어 GitHub Actions(macOS)에서 빌드합니다: Actions → "Native builds" → Run workflow(릴리스 태그 입력 시 릴리스에 첨부), 또는 `v*` 태그 푸시.
  - `AbilityKingdom-ios-simulator.zip`: Mac 시뮬레이터용
  - `AbilityKingdom-ios-unsigned.ipa`: **서명 없는 파일이라 그대로는 아이폰에 설치되지 않습니다.** Apple 계정으로 Sideloadly·AltStore 등에서 서명해 설치하거나(무료 계정은 7일마다 재서명), 유료 Apple Developer 계정으로 TestFlight 배포가 필요합니다.
- 바로 써 보는 방법: 아이폰 사파리에서 공개 링크를 열고 공유 → **홈 화면에 추가**. 리온 아이콘으로 전체 화면 실행됩니다(웹 앱, PWA).
