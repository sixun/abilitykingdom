# 어빌리티킹덤 웹 프로토타입 (v0.2 · 원본 화면 재현)

v0.2에서는 `Ability-Kingdom-Complete-Assets` 패키지(CLAUDE-START-HERE.md)대로 **로비·영입·편성 세 화면을 원본 시안 그대로 다시 만들었습니다.**
새 디자인으로 해석하지 않았습니다. 원본 조각(Original-Pixel-Slices)을 layout.json 좌표 그대로 배치하고, 동적으로 바뀌는 부분만 복원 배경·복원 캐릭터·글자 없는 SVG 스킨과 실제 텍스트로 덮습니다.

공개 링크: https://sixun.github.io/abilitykingdom/

## 실행법

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ 생성 (정적 호스팅 가능, 상대 경로)
npm run test:e2e     # dev 서버 실행 중에 브라우저 자동 검증 (Playwright)
```

- 바로가기: `?screen=lobby`, `?screen=recruit`, `?screen=formation`
- 진행 데이터는 브라우저 localStorage에 저장됩니다. 설정 > 로컬 데이터 초기화로 처음 상태(원본 시안과 같은 값)로 돌립니다.
- 에셋 재생성: `python3 tools/build_ref_assets.py`(원본 조각 → 무손실 WebP + layout JSON), `python3 tools/fit_restored.py`(복원 캐릭터를 원본 실루엣에 맞춘 위치·배율 계산)

## 재현 방식

| 항목 | 방식 |
| - | - |
| 캔버스 | 로비 1456×818, 영입·편성 1456×819 고정 좌표. 화면 크기에 맞춰 캔버스 전체에 **같은 배율 하나만** 적용하고 남는 영역은 검정(레터박스). 개별 요소 늘이기·cover 없음 |
| 기본 표시 | 원본 조각 88개(로비 23 · 영입 25 · 편성 40)를 원래 좌표에 배치. PNG를 픽셀 동일한 무손실 WebP로 변환(용량 절감) |
| 동적 표시 | 상태가 원본 시안 값과 같으면 원본 조각 그대로. 바뀐 영역만 조각을 숨기거나 스킨+HTML 텍스트로 덮고, 비는 자리는 복원 배경으로 채움 |
| 버튼 | 원본 조각 경계에 맞춘 투명 `<button>`(접근성 이름 포함). 누름·포커스는 CSS로 표시 |
| 복원 캐릭터 | 원본 조각을 그대로 복사하지 않고, 원본 실루엣 마스크와 겹침이 가장 큰 배율·위치를 계산해 얼굴·어깨 위치를 맞춤(`ref-fit.json`). 원본의 하체 가림(전경·하단 바)도 유지 |

## 원본 비교 (docs/review/)

브라우저(Chromium, 원본과 같은 크기)로 렌더한 결과를 원본과 픽셀 비교했습니다.

| 화면 | 기본 상태 픽셀 일치 | 비교 이미지 | 동적 변경 예시 |
| - | - | - | - |
| 편성 | 100.00% | compare-formation.jpg | dynamic-formation.jpg (3번 슬롯 교체·팀 전환) |
| 영입 | 100.00% | compare-recruitment.jpg | dynamic-recruitment.jpg (다른 배너 선택) |
| 로비 | 99.82% | compare-lobby.jpg | dynamic-lobby.jpg (재화 변화) |

로비의 0.18% 차이는 원본에 없는 **더보기 메뉴 버튼**(상단 822,20)을 추가한 자리입니다.

## 화면별 상태

### 편성 (1456×819)

**작동하는 것**
- 뒤로가기(저장 전이면 저장/변경 취소/계속 편집 확인)
- 팀 01~03 전환(팀별 저장), 팀 이름 수정
- 캐릭터 4명 각각과 이름표 선택, 상세(i)
- 바닥 슬롯 선택
- 하단 보유 캐릭터로 교체 또는 위치 교환(중복 배치 금지)
- 리더 지정·빼기 팝업
- 자동 편성(임시 규칙: 전투력순), 초기화(마지막 저장 상태로), 저장
- 팀 전투력 자동 계산(원본 4명 기준 24,680이 나오도록 계수 조정)

**정적인 것**
- 배경과 상단 장식
- 하단 바의 원본 아이콘 그림
- 원본 4명의 대기 자세(원본 조각은 한 장 그림이라 움직이지 않음)

**복원·임시로 원본과 달라지는 것**
- 교체되어 원래 자리가 빈 곳은 AI 복원 배경으로 채웁니다. 건물·바닥 세부가 원본과 다릅니다.
- 지안·유진·하린·도윤이 다른 슬롯으로 옮겨지면 AI 복원 전신을 씁니다. 얼굴·옷 주름 세부가 원본과 다릅니다.
- 세인·나린·리온·서하는 복원 전신이 없어 v0.1의 임시 AI 컷아웃을 씁니다. **그림체가 맞지 않습니다.**
- 이름표·팀 탭·전투력은 바뀔 때만 글자 없는 SVG 스킨과 실제 텍스트로 덮습니다. 스킨은 원본을 단순화해 새로 그린 것이라 질감이 원본과 다릅니다.
- 추가 요소: 저장 전 변경 표시, 리더 지정 팝업, 확인 대화상자. 원본에 없어 v0.1 스타일로 그렸습니다.

### 영입 (1456×819)

**작동하는 것**
- 뒤로가기, 한정/상시 탭
- 왼쪽 배너 4개 선택
- 다이아·티켓 충전(상점 이동)
- 상세 정보(영입 기록 링크 포함), 확률 정보(샘플 표기)
- 교환소, 영입 포인트
- 1회·10회 영입: 요청 ID 기반으로 중복 차감 없음 → 결과 화면
- 재화·티켓·포인트 수치는 바뀔 때만 실제 텍스트로 표시

**정적인 것**
- 기본 배너(리온)의 키비주얼·제목·소개 문구·왼쪽 배너 그림
- REC 장식

**복원·임시로 원본과 달라지는 것**
- 리온 이외 배너 3개는 원본 키비주얼이 없습니다. 복원 옥상 배경 + v0.1 임시 캐릭터 + 실제 텍스트 제목으로 표시하고, 화면에 "원본 키비주얼 없음 · 임시 표시"라고 적었습니다.
- 복원 리온 전신은 기본 배너가 원본 조각 그대로라 쓰지 않았습니다.

### 로비 (1456×818)

**작동하는 것**
- 뒤로가기(타이틀로 확인)
- 프로필, 행동력·크레딧·교환 메달(상점 이동)
- 이벤트 3개(스토리·도시 탐색·현상수배)
- 하단 메뉴 10개(스토리·도시 탐색·현상수배·훈련·아레나·레이드·캐릭터·편성·상점·영입)
- 로비 캐릭터 변경 창
- 더보기 메뉴(추가 요소): 가방·우편함·미션·공지·이벤트·출석·프로필·설정·감상 모드
- 감상 모드: UI 조각을 숨기고 복원 배경으로 채움
- 재화·레벨·이름은 바뀔 때만 실제 텍스트로 덮음

**정적인 것**
- 누운 지안과 카페 장면 전체
- 하단 메뉴의 빨간 "!" 표시: 원본 그림에 포함되어 있어 실제 알림 상태와 무관하게 항상 보입니다.

**아직 안 되는 것**
- 지안 이외 캐릭터의 로비 포즈 그림이 없어 캐릭터 변경 창에서 지안만 선택할 수 있습니다.
- 소파 앞쪽 가림 마스크가 없어 로비 캐릭터 등장 연출을 넣지 않았습니다. 캐릭터를 맨 위에 얹는 방식은 원본 가림 관계를 깨므로 쓰지 않았습니다.

## 영상·리깅

- **오프닝**: 사용자 제공 영상(15초)을 H.264 MP4(1080p/720p)와 VP9 WebM으로 변환해 사용합니다.
  - 영상 속 타이틀(13초)부터 입력을 기다리고, 입력 없이는 넘어가지 않습니다.
  - 영상을 불러오지 못하면 정적 타이틀로 대체합니다.
- **없는 것**
  - 캐릭터 입장 영상
  - 리깅: 파츠 분리 PSD, Live2D, Spine
  - 표정별 프레임
  - 정밀 전경 가림 마스크와 그림자

  지금 캐릭터 "움직임"은 교체 시 정지 그림이 들어오고 나가는 CSS 연출뿐입니다.

## 확정 원본이 없는 화면

캐릭터 목록·상세, 상점, 가방, 여섯 콘텐츠(스토리·도시 탐색·현상수배·훈련·아레나·레이드), 출전 준비, 테스트 전투, 영입 결과·기록, 우편·미션·공지·출석·설정은 **v0.1에서 임의로 만든 흐름 검증용 화면**이며 확정 디자인이 아닙니다. 원본 시안이 나오면 같은 방식으로 다시 만들어야 합니다.

## 검증 (2026-10-12)

- `npm run test:e2e` 두 스크립트 실패 0, 콘솔 오류 0. 편성 흐름은 원본 크기(1456×819)에서 검증했습니다.
  - 오프닝 13초 이후 입력 대기, 오프닝에 한글 없음, 영상 차단 시 정적 타이틀
  - 원본 기본 편성(지안·유진·하린·도윤), 교체 시 바뀐 슬롯만 동적 인물, 원래 조각 숨김
  - 위치 교환, 저장 전 이탈 확인, 연타 후 최종 선택 일치, 팀 이름·리더·팀 전환, 초기화·자동 편성, 새로고침 복원
  - 로비 메뉴 링크 진입·복귀, 영입 1회/10회 1회 차감, 상점 재시도 중복 방지, 우편·미션·출석 1회 수령
- 화면비: 1456×819, 1920×1080, 1280×720, 1024×768(4:3, 상하 검정), 915×412(휴대폰 가로)에서 같은 배율·검정 여백을 확인했습니다.
- 아직 측정하지 않은 것: 실제 모바일 기기 성능, iOS Safari 실기기 영상·오디오 재생, 노치 안전 영역.

## 구조

```
public/ref/{lobby,recruitment,formation}/  원본 조각(무손실 WebP)
public/ref/restored/                       AI 복원 배경 3 · 캐릭터 6
public/ref/ui/{skins,icons}/               글자 없는 SVG 스킨 27 · 아이콘 22
src/game/data/ref-*.json                   조각 좌표(layout), 복원 캐릭터 맞춤값(ref-fit.json)
src/ui/ref.tsx                             RefStage(단일 배율·레터박스), RefLayers, Hit(투명 버튼), Patch(스킨+텍스트)
src/screens/{Lobby,Recruit,Formation}.tsx  원본 재현 화면
src/game/                                  데이터 타입·규칙·GameService(로컬 구현, 서버로 교체할 경계)
tools/                                     에셋 변환·복원 캐릭터 맞춤·글꼴 서브셋 스크립트
tests/                                     자동 검증
```

## 확정 필요 범위 (변동 없음)

- 엔진: 미정(웹은 임시)
- 전투 방식, 서버·계정·결제, 확률·천장·가격·성장 공식: 모두 미정
- 아레나·레이드·도시 탐색의 실제 규칙
- 일일 초기화, 행동력 회복, 친구·길드
- 캐릭터 이름·수치·대사: 샘플이며 세계관 문서와 아직 맞추지 않았습니다.
